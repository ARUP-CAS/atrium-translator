## 🧩 Design — pluggable backends behind one seam
A `@runtime_checkable` `TranslationBackend` Protocol (`name`, `supports_glossary`, `translate(text, src, tgt="en")`, `supported_languages()`) with a `get_backend(name, **kwargs)` factory. Resolution order: `--backend` → `config.txt: translation_backend` → env `TRANSLATION_BACKEND` → fallback `"lindat"`. Beyond the Protocol, a backend exposes a pipeline-compatibility surface: `vocabulary`, `reset_protected_count()`, `protected_count`, and `license_components(vocab_loaded)`.

## ✅ Verified live
The seam is wired into real entry points — `main.py:312` (`get_backend(args.backend, vocab_path=args.vocabulary)`) and `service/api.py:37` (`get_backend(TRANSLATION_BACKEND)`). Resolution order is active and tested. `backend._ensure_registry` registers `lindat` + `openai_compatible` (with `ct2` as a scaffolded option).

## 🚚 Shipped backends
- **`lindat`** (default) — `LindatTranslator`, LINDAT/CUBBITT NMT. `supports_glossary=False` → terminology via in-process **Tag-and-Protect** + UDPipe; cs-centric. CC BY-NC-SA 4.0.
- **`openai_compatible`** — `LLMTranslator` (Phase 1). OpenAI-compatible REST adapter (`/v1/chat/completions`) reaching free/cloud providers via `LLM_BASE_URL` / `LLM_MODEL` / `LLM_API_KEY`. `supports_glossary=True` (prompt-injected, retiring Tag-and-Protect for this backend). Features temp 0, OCR-faithfulness guards, and length-ratio validation.
- **`ct2`** — `CT2Translator` (Phase 3). CTranslate2 int8/int4 self-host for **EuroLLM-1.7B/9B** or **MADLAD-400-3B** (both Apache-2.0). Heavy dependencies are imported lazily inside methods.

## ⚖️ Licensing recipe
Permissive output requires eliminating NC components across the pipeline:
1. **Model:** Use `--backend ct2` with an Apache-2.0 model (EuroLLM / MADLAD-400).
2. **Language ID:** Pass explicit `--source_lang` (bypasses default FastText CC BY-NC 4.0 detector).
3. **Glossary:** Provide a permissive or empty vocabulary file.

## 📝 Landed & hardened changes
- **Architecture:** Seam integrated in `main.py` and `service/api.py`.
- **Reliability:** Added `max_tokens` (LLM) and `max_decoding_length=2048` (CT2) to prevent truncation. Added strict length-ratio guards and word-boundary matching (`\b`) for glossaries.
- **Service & Paradata:** Fixed `/translate` streaming race condition by buffering in-memory `Response`. Compiled XSD once per run. Dynamic API paradata logging via `license_components()`. Hardened Dockerfile.
