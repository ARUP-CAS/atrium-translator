## Context

The pluggable translation backend architecture (`TranslationBackend` Protocol, `get_backend()` factory, CLI and API integration) is verified and live. The outstanding task for Issue #4 is to finalize the actual model selection by running a definitive empirical bakeoff and establishing the open-source self-hosting recipe (`ct2`).

We need a documented, data-backed decision on which model offers the highest translation fidelity for historical archaeological text without hallucinating or corrupting XML/ALTO layout bounding boxes.

## Execution Plan

### Phase A — Documentation & Path Verification
- Ensure `docs/translation-backends.md` is updated to reflect all available backends (`lindat`, `openai_compatible`, `ct2`).
- Verify that all references in code (`processors/backend.py`, `processors/translator.py`, `tests/test_backend.py`) point correctly to `docs/translation-backends.md`.

### Phase B — Live LLM Backend Smoke Test
- Live-smoke the `openai_compatible` backend against an active endpoint (e.g. OpenRouter free tier, Cohere, or local Ollama) using real AMCR and ALTO XML samples.
- **CLI Test:** Run `python main.py ./data_samples/my_documents --alto --formats alto.xml --backend openai_compatible --source_lang cs --vocabulary data_samples/vocabulary.csv`.
- **API Test:** Start `service/api.py` with `TRANSLATION_BACKEND=openai_compatible`, POST an ALTO document to `/translate`, and ensure the in-memory `Response` returns valid XML under load.
- **Guards Verification:** Confirm that temperature 0, prompt-injected glossary, and length-ratio safety checks operate as intended without dropping ALTO bounding boxes.

### Phase C — Execute Translation Bakeoff (`eval/bakeoff.py`)
Run the evaluation harness on a representative sample set of AMCR metadata and ALTO OCR files _(2026-09-26: weighted to AMČR `metadata-en` free-text fields; ALTO a secondary slice)_:
```bash
python -m eval.bakeoff \
    --backends lindat,openai_compatible,ct2 \
    --samples data_samples/my_documents \
    --vocabulary data_samples/vocabulary.csv \

    --limit 40 \
